# 드라이브 영상 갤러리

구글 드라이브 영상을 **내가 고른 장면**을 썸네일로 해서 모아 보는 개인용 갤러리. PC·폰 브라우저 모두 사용.

- 내가 올린 드라이브 영상 전부를 폴더 구분 없이 한 화면에 보여줌.
- 탐색 바: `🔍` + `태그` · `카테고리` · `장르` · `캐릭터` · `시리즈`. 같은 버튼을 다시 누르면 전체 영상.
  돋보기는 전체 영상 화면에서 파일 이름을, 분류 화면에서는 그 유형의 태그 이름을 부분 검색. 검색을 닫아도 선택한 유형은 유지.
  유형을 누르면 해당 태그 목록, 태그를 누르면 그 태그가 붙은 영상만 표시.
  수정 ON에서는 즐겨찾기·수정·삭제와 하단의 다른 세 유형으로 이동하는 메모가 표시됨. 기존 태그를 적고 Enter 또는 전송으로 이동하며 입력칸 포커스 유지.
  메모에서 Tab은 다음 메모로, 마지막에서는 첫 메모로 순환. Shift+Tab은 반대 방향.
  분류는 태그 자체를 지우지 않고 `gallery.json`의 `tagKinds`에 저장.
  위쪽 헤더(제목·수정·로그아웃)는 따라오지 않고 페이지 맨 위에 남으며, 이 바만 화면 맨 위에 붙어 따라옴(PC·폰 공통, 칸이 넘치면 옆으로 밀어 스크롤)
  즐겨찾기는 위쪽 별도 영역과 구분선으로 표시하며, 같은 영상이 본래 목록에도 그대로 남음.
  드라이브에 새로 올린(지운·이름 바꾼) 영상은 새로고침 없이 반영: 이 탭으로 돌아올 때와 보는 동안 2분마다 목록을 다시 확인(30초 안엔 다시 안 물음, 입력 중이면 미룸).
  오른쪽 아래 새로고침 아이콘 = 자동 정렬, 그 왼쪽 동그라미 [↑] = 맨 위로(편집 중엔 가운데 파란 네모가 대신함).
  자동 정렬을 누르면 같은 제목에 번호 붙은 영상이 2개 이상일 때 빈 번호를 당김(3~7 → 1~5, 1·4~8 → 1~6, 확인 창 뒤 드라이브 이름 변경). 번호 없는 제목엔 안 붙이고, 번호 붙은 게 하나뿐인 제목은 그대로.
  본문 정렬(자동 정렬): 태그 있는 영상 먼저, 태그 없는 영상은 맨 뒤(제목 순). 태그 있는 영상은 아래 순서로 비교:
  1) 장르: 많이 쓰인 장르 먼저(없으면 뒤) 2) 캐릭터: 그 장르 안에서 많이 쓰인 캐릭터 먼저(없으면 뒤)
  3) 카테고리: 그 장르·캐릭터 안에서 많이 쓰인 카테고리 먼저(없으면 뒤)
  4) 번호 제목 묶음: 장르·캐릭터·제목 앞부분이 같고 끝이 숫자인 영상이 2개 이상이면 묶어서 번호 순. 묶음은 한 덩어리로, 구성원 중 가장 많이 쓰인 카테고리를 따름
  5) 태그 수 많은 순 6) 앞 영상과 겹치는 태그가 많은 영상을 이어 붙임.
  장르·캐릭터·카테고리가 여러 개면 사용량이 가장 큰 태그가 기준(전체 영상 기준으로 셈). 동률은 특수문자·글자·숫자 순 태그명, 다음 제목.
  카테고리는 장르·캐릭터 안에서만 모이므로, 장르·캐릭터가 다르면 같은 카테고리가 떨어져 나올 수 있음. 하트가 본문 순서를 바꾸지 않음, 시리즈는 처음 나오는 자리에 저장 순서대로 붙음.

- 수정 ON에서 탐색 바 오른쪽 `시리즈 지정`: 썸네일을 누른 순서대로 선택한 뒤 저장.
  이름은 첫 영상의 장르·카테고리 태그와 번호로 자동 생성. 장르가 없으면 캐릭터 태그를 대신 사용.
  다시 지정 모드에 들어가면 기존 시리즈는 노란 테두리 묶음으로 표시. 묶음을 골라 다른 영상을 추가하거나, 묶이지 않은 영상부터 골라 새 시리즈 생성.
- `시리즈` 탭은 저장된 재생목록을 표시. 수정 ON이면 이름 변경·묶음 해제·썸네일 드래그 순서 편집 가능.
  순서 편집은 저장해야 반영되며 취소하면 기존 순서 유지. 묶음 해제는 재생목록 정보만 삭제하고 원본 영상·태그·썸네일은 유지.
  시리즈 정보는 `gallery.json`의 `series`에 저장. 기본 목록에서도 시리즈가 처음 나타나는 위치에 지정 순서대로 붙고, 검색·숨김으로 제외된 영상을 다시 넣지는 않음.
  PC 영상 창 좌우의 〈 / 〉와 폰 좌우 넘기기도 저장 순서를 따름. 이전·다음 영상은 현재 검색·필터 결과 안에서 이동.

- 왼쪽 아래 `☰` 메뉴: PC는 왼쪽에서 밀려 나오는 패널(헤더 아래~화면 끝, 뒤를 어둡게 하지 않음, 내용이 길면 안에서 스크롤), 폰은 아래에서 올라오는 시트.
  조건은 모두 함께 적용(AND), [검색]을 눌러야 반영되고 적은 내용은 그대로 남음(PC 패널은 열린 채). `↻` = 조건 초기화. 걸린 조건은 위쪽 `🔎 조건 N개 ✕` 로도 해제
  - 태그 검색: 입력한 글자가 들어간 태그를 추천(예: `4` → 4k). 비어 있거나 맞는 게 없으면 즐겨찾기 5개(없으면 많이 쓴 태그 5개). 고른 태그가 모두 있는 영상만
  - 필터: 고른 태그가 하나라도 붙은 영상은 숨김. 비어 있으면 내가 필터로 많이 쓴 태그 10개를 미리 보여줌(횟수는 gallery.json 에 저장)
  - 통합 검색(제목 또는 태그), 길이(분, 최소만/최대만/둘 다), 카테고리(표시 중인 것만, 여러 개)
  - 바로 반영: `N단`(폰, 누를 때마다 1→2→3→4, 기기에 기억), `랜덤`(지금 보이는 영상만 섞음, 다시 누르면 기본 정렬)
  - 수정 ON: 알약의 ☆ 를 누르면 즐겨찾기, `제목의 [ ] 를 태그로 옮기기`(한 번 더 눌러 시작 → [ ] 안 글자는 태그로, 드라이브 파일 이름에서는 뺌. 실패하면 첫 실패 이유가 위쪽에 뜸)
- 영상 창의 태그: 메모 칸은 늘 열려 있음. 쉼표(띄어쓰기도 쉼표로 바뀜)로 적고 Enter·`작성 완료` → 위쪽 (★ 4k (5)) 알약에 더해지고 칸은 비워짐.
  `+` 하나 추가(다른 영상의 태그를 많은 순으로 추천), `수정` 전체 태그를 메모 칸에 펼쳐 고친 뒤 Enter 로 통째로 바꿈(Esc 취소).
  수정 ON: 알약의 ☆ 를 정확히 누르면 즐겨찾기(노란 ★), 연필 = 이 영상의 태그만 이름 바꾸기(Enter 저장, 다른 곳 누르면 취소. 모든 영상의 태그 이름은 분류 칸 연필에서 — 10개 이상이면 확인 창). 칸 아래 `모든 태그`(이 영상에 없는 것, 많은 순)를 누르면 이 영상에 붙음.
  태그·즐겨찾기는 gallery.json 에 저장돼 PC·폰 공통
- 수정 ON에서 영상 창 제목 오른쪽 하트는 썸네일 하트·핑크 테두리와 상단 즐겨찾기 영역 표시. 별은 아이콘 없이 초록 테두리, 네모는 갈색 테두리.
  별·네모는 서로 전환되며 하트가 함께 켜져 있으면 핑크 테두리 우선. 표시 상태는 `marks`에 저장.
  썸네일 아래 태그는 카테고리 → 장르 → 캐릭터 → 일반 태그 순서, 같은 유형 안에서는 전체 영상에서 많이 사용한 순서.
- 영상 합치기 (수정 ON, PC 크롬·엣지): 헤더 `편집` → 검색·필터로 찾은 영상의 썸네일을 누른 순서대로 담음(◀ ▶ 로 순서 변경).
  담은 영상 목록 아래 `맨 앞 1초 장면 고르기`: 담은 영상들의 지정 썸네일을 누르거나, 영상 아래 가위로 그 영상의 한 지점을 찍으면(`이 지점으로 썸네일 설정`) 합친 영상 맨 앞에 1초 들어감(하나만). 고른 장면은 목록 맨 앞 0번 칸으로 보임. 이름을 적고 `합치기`.
  `합치기`는 작업 목록에 넣고 담기 칸을 비움 → 바로 다음 합치기를 담을 수 있음. 작업은 하나씩 차례로(작업마다 진행률·취소, 하나가 실패해도 다음 작업은 계속). 이미 작업에 들어간 영상은 흐리게 보이고 다시 담을 수 없음.
  작업마다 임시 파일 이름이 달라 탭을 여러 개 열어도 겹치지 않고, 쓰는 동안 잠금을 쥐어 갑자기 닫힌 탭이 남긴 임시 파일만 다음 합치기 때 지움.
  서버 없이 이 브라우저가 드라이브에서 조금씩 읽어 → 풀고 → 첫 영상 해상도로 H.264+AAC 로 다시 압축 → 표준 MP4 를 브라우저 임시 저장공간(OPFS)에 만든 뒤 8MB 씩 드라이브에 올림(재개 가능 업로드).
  (조각 MP4 로 바로 올리던 첫 버전은 아이폰 직접 재생에서 앞 몇 초만 나와서 바꿈. 임시 공간은 원본 합의 약 1.3배 필요, 끝나면 지움)
  합친 영상에는 원본들의 태그를 합쳐 붙임(같은 태그는 한 번만). 하트는 하나라도 있으면 하트, 표시는 별이 하나라도 있으면 별, 아니면 네모.
  원본이 번호 붙은 제목이면 합친 뒤 남은 같은 제목들의 번호를 빈칸 없이 다시 매김: 마리오 1~8 중 1~3 을 합치면 남은 4~8 → 1~5.
  합친 영상 이름이 같은 제목에 번호(예: 마리오1)면 그 번호는 비워 두고 채움 → 2~6. 다른 이름(예: 루이지)이면 1~5.
  편집 중엔 화면 아래 가운데 파란 네모 [↑] = 맨 위로
  예전에 만든 조각 MP4 는 영상 창(수정 ON, PC)에 `폰 재생용으로 고치기`가 뜸 → 다시 압축하지 않고 표준 MP4 로 옮겨 담아 같은 파일에 덮어씀(파일·태그 그대로, 드라이브에 이전 버전이 남음)
  첫 영상이 있는 폴더에 올라가고, 다 올라간 걸 확인한 뒤에만 원본을 드라이브 휴지통으로. 실패·취소하면 올리던 파일은 버리고 원본은 그대로.
- 헤더 `모자이크` 탭 (합치기와 별개): `모자이크` 태그가 붙은 영상을 자동 정렬 순서로 모아 보여 주고, 이 PC 의 [Lada](https://github.com/ladaapp/lada)(AGPL-3.0, 별도 설치)로 모자이크를 해제.
  1. Lada 를 `C:\Tools\lada\lada\` 에 풀어 두고(다른 곳이면 환경 변수 `LADA_CLI`), `tools\lada-helper.bat` 을 켬 → `127.0.0.1:7861` 에서 이 사이트(와 로컬 테스트 주소)만 받는 도우미.
  2. 수정 ON 에서 카드를 누르면 작업 대기열에 넣고, 대기 중인 건 다시 누르면 뺌(진행 중인 건 작업 목록의 `취소`로만). `대기열에 모두 넣기`도 있음.
     작업은 하나씩 차례로 돌고, 도는 동안에도 계속 넣을 수 있음. 카드에 `진행 중`·`대기 N` 표시.
  3. 작업 하나: 드라이브에서 8MB 씩 읽어 도우미에 넘김 → Lada(GPU, H.264 출력, `--detect-face-mosaics` 로 얼굴 모자이크는 건드리지 않음)
     → 결과를 브라우저 임시 저장공간에 모아 같은 드라이브 파일에 덮어씀(파일·태그·썸네일 그대로, 드라이브에 원본이 이전 버전으로 30일) → `모자이크` 태그를 뗌.
  4. 취소·실패하면 올리던 건 버리고 원본 그대로(실패한 작업은 `다시`). 도우미가 꺼져 있으면 대기열은 그대로 기다림. 처리하는 동안 이 탭과 도우미 창을 켜 둘 것.
  모자이크 대기열에 든 영상은 합치기에 담을 수 없고, 합치기 작업에 든 영상은 대기열에 넣을 수 없음(서로 간섭하지 않게).
  Lada 는 실사 영상으로 학습된 모델이라 3D 영상에선 결과가 고르지 않을 수 있음 → 몇 개로 먼저 확인.
  로그인이 만료되면 멈췄다가 다시 로그인하면 이어서 함. 합치는 동안 탭을 열어 둘 것. 엔진: `video-merge.js`(Mediabunny 1.60.0, MPL-2.0, `vendor/`), 화면: `merge-ui.js`
- 탐색 바 순서: 태그 → 장르 → 캐릭터 → 카테고리 → 시리즈 → 타이틀. 돋보기는 타이틀 화면에서는 제목만, 그 밖에는 제목+태그 통합 검색
- 모든 영상: 즐겨찾기 아래에 별 표시 영상도 따로 모아 보여줌(구분선, 본래 목록에도 그대로). 수정 ON 이면 카드 오른쪽 아래 빨간 `삭제` → 확인 창에서 삭제(드라이브 휴지통)
- 분류 칸(수정 ON): 아래 3칸 = 즐겨찾기 · 수정 · 휴지통(빨강, 확인 창). 칸을 누르면 이동 메모 아래에 그 영상들이 나오고(누르면 잠시 빼기), 그 영상들에 태그 추가 · 태그 종류 바꾸기 메모
- 태그를 모든 영상에서 빼도(보이는 영상에서 제거 등) 태그 자체는 0개로 남음(`knownTags`). 휴지통으로 지울 때만 없어짐
- 수정 ON 에서 목록 맨 아래 태그 메모: 적고 Enter → 지금 화면에 보이는 영상(검색·필터 결과) 모두에 그 태그를 붙임
- 불러오기: 영상 목록과 gallery.json 을 동시에 받고, gallery.json 은 이 브라우저에 사본을 둬서 드라이브 쪽이 안 바뀌었으면(md5 같으면) 다시 안 받음(로그아웃하면 지움).
  썸네일은 받아지는 대로 하나씩 떠오름
- 폰 영상 페이지: 옆으로 밀면 화면이 손가락을 따라 밀리고 이전/다음 영상이 반대쪽에서 들어옴(지금 목록 순서), 위아래는 스크롤. 열려 있는 동안 뒤 목록은 고정.
  재생 전에는 내가 정한 썸네일(없으면 드라이브 썸네일)이 ▶ 와 함께 떠 있고 누르면 재생. `⛶ 전체화면`은 재생 전에 눌러도 아이폰 전체화면 플레이어로 열림
- 오른쪽 위 `수정` 토글(수정 ON 에서 목록 카드의 제목을 누르면 그 자리에서 이름 바꾸기): OFF(기본)면 영상 재생만, ON 이면 썸네일 수정 버튼이 보임. ON 은 탭을 닫을 때까지 유지(로그아웃·다시 로그인해도 유지)
- 구글 로그인은 1시간짜리라 만료 10분 전부터 클릭하면 자동 연장, 만료되면 `🔑 다시 로그인` → 멈춘 저장 이어서 + 썸네일 안 정한 첫 영상으로 스크롤
  - 확장 프로그램이 없으면 ON 직후 버튼이 `🔓 화면 캡처 허용`으로 바뀜 → 눌러서 크롬 공유 창에서 이 탭 허용 (탭을 닫기 전까지 다시 안 물음)
- 썸네일 지정 방법 (수정 ON, 영상 열기 후)
  - `지금 화면으로 지정` (PC): 원하는 장면에서 누르면 즉시 플레이어 영역만 캡처 → 같은 버튼이 [바꾸기]로 바뀜(옆에 [취소]) → 한 번 더 누르면 저장. 영상 형식 무관
    - 확장 프로그램 없음: 플레이어 컨트롤이 내려간 상태에서 누를 것
    - 확장 프로그램 있음: 공유 허용 없이, 찍는 순간 컨트롤을 자동으로 숨기고 찍음 + 플레이어 아래 `재생/멈춤 / ±1초 / ±1프레임` 버튼. PC는 스크린샷을 Ctrl+V 로 붙여넣어도 됨
      수정 ON 에서는 영상을 클릭해 재생하면 0.3초 뒤 멈춤(자동 멈춤, 계속 보려면 재생/멈춤) + 플레이어 아래 항상 보이는 시간 조절바.
      자동 멈춤은 `수정 ON` 왼쪽 `자동 멈춤 ON/OFF` 로 끄고 켬(기기에 기억). OFF 면 멈추지 않음(영상 창을 열 때 자동 재생은 그대로)
      드라이브 시간표를 클릭해 이동하면 미리보기와 맞도록 자동으로 1초 되돌림.
      수정 ON 으로 영상 창을 열면 자동으로 재생→멈춤까지 해서 드라이브 시간 조절바가 바로 보임
      (불러오는 동안은 대표 장면 뽑기를 잠시 멈춰 플레이어가 먼저 뜨게 함)
  - 대표 장면 5개(25·33·50·66·75%): 수정 ON 이면 아직 썸네일을 안 정한 앞쪽 영상 10개를 뒤에서 한 개씩 순서대로 미리 뽑아 둠(영상 파일에서 직접, 플레이어는 안 건드림).
    영상 창 아래에 뜨고 누르면 바로 적용. 브라우저가 못 푸는 형식(예: 이 PC가 못 푸는 HEVC)이면
    확장이 화면 밖에 숨긴 드라이브 플레이어로 대신 뽑아서 붙임(보이는 플레이어는 안 건드림, 확장 2.0 필요)
  - [바꾸기]·대표 장면을 고르면 창은 바로 닫히고 저장은 뒤에서 순서대로 (위쪽에 진행 표시)
- 수정 ON 에서 영상 창 오른쪽 아래 **숨기기**: 갤러리에서만 숨김(드라이브 파일은 그대로, 숨김 목록은 gallery.json 에 저장돼 폰에도 반영).
  위쪽 "숨긴 영상 (N)" 버튼으로 흐리게 다시 보고(보는 중엔 파란색), 열어서 숨김 해제
- 수정 ON 위쪽 **[복원]**: 가장 최근 작업(태그 붙이기·빼기·이름 바꾸기, 종류·즐겨찾기·별·숨김, 드라이브 파일 이름 바꾸기 등)을 반대로 되돌림.
  누를 때마다 한 작업씩 더 앞으로 (2초 넘게 쉬었다가 한 변경은 새 작업). 백업 파일 없이 바뀌기 직전 값만 기억하므로 페이지를 닫으면 사라짐.
  10개 이상 바뀌는 작업은 확인 창이 먼저 뜸. 썸네일, 휴지통 보내기, 합치기(새 영상 만들기·원본 휴지통)는 되돌리지 않음
- 수정 ON 에서 영상 창 위쪽 **이름을 누르면 이름 바꾸기**(Enter 저장, Esc 취소), 오른쪽 아래 **휴지통 → 한 번 더 누르면 드라이브 휴지통으로**(30일 안에 복원 가능)
  - 이 두 기능은 드라이브 수정 권한이 필요해서, 처음 쓸 때 구글 확인 창이 한 번 뜸 ("Google Drive 파일 보기·수정·생성·삭제" 체크).
    필요 없어지면 https://myaccount.google.com/permissions 에서 앱 권한을 지울 수 있음
- 썸네일·시점은 내 드라이브의 **숨김 앱 폴더(appDataFolder)** 에 저장 → PC에서 지정하면 폰에도 반영.
  `gallery.json` 엔 시점·태그 등과 썸네일 파일 ID만, 지정 썸네일 이미지는 영상마다 따로 `thumb-영상ID.jpg` 파일. 카드가 화면 근처에 올 때 받아 이 브라우저에 캐시.
  예전처럼 이미지가 gallery.json 안에 들어 있으면 불러올 때 20개씩 파일로 옮김("🖼️ 썸네일 정리 중")
- 영상 원본은 읽기만 하고 절대 수정하지 않음. 별도 서버 없음 (GitHub Pages 정적 페이지 하나)

## 처음 한 번: Google Cloud 설정 (약 10~15분)

1. https://console.cloud.google.com 접속 → 상단 프로젝트 선택 → **새 프로젝트** (이름 예: `drive-gallery`) → 만들기
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용**
3. **Google 인증 플랫폼(OAuth 동의 화면)** → 시작하기
   - 앱 이름: `드라이브 영상 갤러리`, 사용자 지원 이메일: 본인 Gmail
   - 대상: **외부(External)**
   - 연락처 이메일: 본인 Gmail → 동의 후 만들기
4. **대상(Audience)** → 테스트 사용자 → **+ Add users** → 본인 Gmail 추가 → 저장
   (게시 상태는 "테스트"로 그대로 둠. 본인만 쓰는 용도라 앱 검수 불필요)
5. **클라이언트** → **+ 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본에 추가:
     - `https://srsplitter.github.io`
     - `http://localhost:8080` (로컬 테스트용, 선택)
   - 만들기 → 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`) 복사
6. 사이트 첫 화면에 클라이언트 ID 붙여넣기 → 저장
   (또는 `index.html` 의 `const CLIENT_ID = ''` 에 넣어 배포하면 폰에서도 입력 없이 바로 사용)

> 클라이언트 ID는 공개돼도 되는 값입니다(비밀번호 아님). **클라이언트 보안 비밀(secret)은 필요 없으니 어디에도 넣지 마세요.**

### 첫 로그인 시
- "Google에서 확인하지 않은 앱" 경고 → **고급 → 드라이브 영상 갤러리(으)로 이동** (내가 만든 테스트 앱이라 정상)
- 권한 체크박스 2개(드라이브 보기, 앱 데이터)를 모두 체크
- 로그인은 1시간 유지. 만료되면 로그인 버튼 한 번 다시 누르면 됨

## 확장 프로그램 설치 (선택, PC 크롬·엣지)

공유 허용 없이 캡처하고, 찍을 때 플레이어 컨트롤을 자동으로 숨기고, 재생/프레임 이동 버튼을 쓰려면 설치하세요.

1. [extension.zip](https://github.com/srsplitter/drive-gallery/raw/main/extension.zip) 을 받아 압축을 풀고 `extension` 폴더 위치를 기억해 두세요.
   (이 저장소를 받아 둔 PC라면 `drive-gallery\extension` 폴더를 그대로 써도 됩니다)
2. 크롬 주소창에 `chrome://extensions` (엣지는 `edge://extensions`) → 우측 상단 **개발자 모드** 켜기
3. **"압축해제된 확장 프로그램을 로드합니다"** → `extension` 폴더 선택
4. 갤러리 페이지를 새로고침 → `수정 ON` 이 바로 켜지고(허용 단계 없음) 영상 창에 `재생/멈춤` 버튼이 보이면 성공

- 이 확장은 갤러리 페이지(`srsplitter.github.io/drive-gallery`)의 요청만 받습니다. 그 탭 화면만 찍고, 다른 사이트에서는 아무것도 하지 않습니다.
- 설치할 때 "모든 웹사이트의 데이터 읽기·변경" 경고가 뜨는 건, 크롬이 공유 허용 없이 탭 화면을 찍는 기능(`captureVisibleTab`)에 이 권한을 요구하기 때문입니다.
- 확장을 수정·업데이트한 뒤에는 `chrome://extensions` 에서 새로고침(↻) 버튼을 누르세요.

## 참고 / 한계
- 아이폰 HEVC `.mov` 는 크롬에서 장면 지정용 재생이 안 될 수 있음 → 엣지(HEVC 확장)·사파리 사용
- 영상 재생: PC는 영상 창 안의 드라이브 플레이어.
  폰은 드라이브 플레이어가 로그인 쿠키를 못 받아(사파리 크로스 사이트 추적 방지) 멈추므로, 갤러리가 영상 파일을 드라이브 API 로 직접 받아
  폰 기본 플레이어로 재생(`sw.js`). 응답은 항상 206(아이폰은 200이 오면 재생 거부)이고 4MB 조각마다 다음 조각 2개를 미리 받아 두어
  드라이브 응답 대기 때문에 끊기지 않게 함(추적 방지 설정 그대로, 앱으로 안 넘어감).
  폰 브라우저가 못 푸는 형식(avi·mkv·wmv 등)은 썸네일을 누르면 바로 드라이브(앱)로 열림 → 화면 왼쪽 위 "◀ Safari" 로 갤러리에 돌아옴.
  재생이 안 되면 영상 아래에 이유가 뜨고 `드라이브에서 열기`
- 폰에서는 영상 창이 화면 전체 페이지로 열림. 왼쪽 위 `← 돌아가기` 또는 폰의 뒤로 가기로 목록으로
- 현재는 "내 드라이브" 폴더 탐색만 지원 (공유 문서함·공유 드라이브 미지원)
